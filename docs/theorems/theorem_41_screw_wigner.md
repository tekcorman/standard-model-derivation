Princeton University Press. Chapter 4, Eq. 4.1.15. The Wigner D-matrix D¹_{m'm}(α,β,γ)
for Euler angles (α,β,γ) gives the j=1 representation of any SO(3) rotation.

For R₄ expressed in the [111]-aligned frame, the Euler ZYZ decomposition gives angles
(α, β, γ) with β ≈ arccos(1/√3) ≈ 54.7356° (the axis tilt angle computed in §2).

**D-matrix computation.** The Wigner D-matrix for j=1 in the basis |+1⟩, |0⟩, |−1⟩
(spherical harmonic basis) via the change-of-basis U from Cartesian to spherical:

```

     [     0,      0, 1],
     [ 1/√2, -i/√2, 0]]
```

D = U R₄^{[111]} U⁻¹.

**Type 2 gate:** explicit matrix multiplication (see §CAS verification for internal CAS note).
