Files here **touch observed numbers** to compare the forced-math results against experiment. By the
project discipline (the sealed-mathematician protocol) this comparison is done **separately and
afterward** — it is the *firewall*, not part of the forced derivation. Keep it out of the pure-math core.

  reads off the clock value δ that matches. This is the "set one observable, predict the rest" firewall
  test, NOT a forced derivation.
- `CLOSURE_seam_and_delta.md` — the narrative of the lepton-sector closure and its honest retraction;
  references the observed 206.77 comparison.

Nothing in the pure-math core imports these files.
