# derivation_topdown — the pure-math, top-down sub-project

This is a **separate sub-project** from the physics derivation in the parent directory
(`Standard Model from First Principles`). Keep the two cleanly separated.

## What this is

The **walled "mathematician in a box"** exercise: start from the bare object **{D, srs, MDL}** (the
Dirac operator D on Sunada's K₄ crystal net, with minimum-description-length as the generative
principle) and ask, **purely mathematically**, what *structure, dynamics, and interaction the math
forces* — top-down, with **no physics input of any kind**: no observed numbers, no targets, no fitting,
no Standard-Model vocabulary used as a premise. The comparison to physics (the "firewall") is done
*separately and afterward*, never inside the derivation.

## Layout

- `dirac_srs_mdl/` — the bare object: the K₄ crystal, the Dirac/Hodge operator, the Ihara/Hashimoto
  (non-backtracking) spectrum, the spectral action. Self-contained and independently verified.
- `matter_bridge/` — the Clifford tower (Cl(3)→Cl(4)), the srs⊕srs-z doubling, the internal algebra.
- `time_bridge/` — Tomita–Takesaki modular flow; the type-III₁ "intrinsic time generated by D".
- `interaction/` — the staged-interaction interval (dimensional transmutation of the one scale).
- `bridge/` — later consolidation + the firewall-comparison scratch (this layer DOES touch observed
  numbers for comparison; it is *not* part of the pure-math core — see CLEANROOM_FORCED_STRUCTURE.md).
- `CLEANROOM_FORCED_STRUCTURE.md` — the consolidated map of what {D, srs, MDL} forces ([F]/[I]/[O] tags).

## Relationship to the physics project

- This sub-project **imports nothing** from the physics side.
- The physics side reaches in only via `dirac_srs_mdl/srs.py` (the crystal object); those imports rely
  on an external cwd/PYTHONPATH convention (run with `derivation_topdown/dirac_srs_mdl` on the path).

## Discipline (do not violate)

Any in-wall probe must be run by an agent that sees ONLY these directories, asked to derive the
mathematics — never led with physics, targets, or the expected answer. See the project memory
`sealed-mathematician-protocol`.
